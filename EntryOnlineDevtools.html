개인정보 처리방침

시행일자: 2026년 6월 14일

Entry Online 개발자 도구(이하 "본 확장 프로그램")는 엔트리 작품의 온라인 멀티플레이 동작을 하나의 브라우저에서 여러 화면으로 시험하기 위한 Chrome 확장 프로그램입니다. 공개 작품은 일반적으로 접근 가능한 상태에서 테스트할 수 있으며, 비공개 작품은 해당 작품의 소유자가 playentry.org에 로그인한 상태에서 테스트하는 것을 전제로 합니다. 본 방침은 확장 프로그램이 기능 제공 과정에서 다루는 데이터와 권한의 사용 목적을 설명합니다.

본 확장 프로그램은 엔트리의 공식 확장 프로그램이 아닙니다. 서버 기반의 Entry Online 서비스와 별개이며, 해당 서비스의 서버 또는 작품 등록·승인 정보에 연결하거나 이를 조회하지 않는 로컬 테스트 도구입니다.

1. 처리하는 데이터

본 확장 프로그램은 기능 제공을 위해 다음 데이터를 사용자의 브라우저 안에서 처리합니다.

  • 작품 식별 정보: 현재 열려 있는 엔트리 작품의 작품 ID
  • 테스트 설정: 사용자가 선택한 테스트 인원 수
  • 작품 실행 데이터: 테스트 대상 작품의 $ 접두 변수·리스트의 이름, 내부 식별자 및 값
  • 로컬 세션 정보: 임의 세션 토큰, 생성·만료 시각, 가상 방 ID, 화면별 슬롯 번호, 연결 상태와 화면 구성 정보

이름, 이메일 주소, 전화번호, 위치정보, 결제정보 또는 사용자의 엔트리 로그인 자격 증명을 별도로 수집하지 않습니다. 비공개 작품은 브라우저가 playentry.org에 이미 보유한 로그인 세션으로 엔트리 사이트에서 직접 불러오며, 본 확장 프로그램은 로그인 쿠키나 비밀번호를 읽거나 저장하지 않습니다. 다만 작품 제작자가 변수나 리스트에 개인정보를 직접 입력한 경우 해당 값이 로컬 테스트 과정에서 처리될 수 있으므로, 민감한 정보는 테스트 변수·리스트에 입력하지 않아야 합니다.

2. 처리 목적

  • 사용자가 확장 팝업에서 선택해 로컬 테스트를 시작한 엔트리 작품을 여러 iframe 화면으로 실행
  • 동일 브라우저 안의 테스트 화면 사이에서 변수·리스트 상태 동기화
  • 화면별 사용자 번호, 연결 상태와 방 상태 표시
  • 선택한 작품 ID, 테스트 인원 수와 임시 세션 토큰을 이용한 로컬 테스트 화면 구성

3. 외부 전송 및 제3자 제공

본 확장 프로그램은 작품 ID, 테스트 설정, 변수·리스트 값 또는 로컬 세션 정보를 개발자가 운영하는 서버나 Entry Online 서버로 전송하지 않습니다. Entry Online의 작품 등록·승인 정보를 조회하지 않으며, 작품의 $입장 함수 인자는 서버 식별이나 로컬 방 구분에 사용하지 않습니다. 화면 간 동기화는 동일 브라우저의 엔트리 페이지와 iframe 사이에서 window.postMessage를 이용해 처리됩니다. 임시 세션 토큰은 URL 해시 부분에만 담겨 playentry.org 서버 요청에 포함되지 않습니다.

테스트할 작품 화면은 playentry.org에서 직접 제공되므로 작품 로드와 기존 로그인 세션의 처리는 엔트리 웹사이트에서 이루어집니다. 분석 SDK, 광고 네트워크, 원격 로깅 서비스 또는 데이터 중개 서비스를 사용하지 않으며 사용자 데이터를 판매하지 않습니다. 엔트리 웹사이트와 작품 자체에서 이루어지는 데이터 처리는 해당 서비스 또는 작품 제공자의 정책이 적용됩니다.

4. 저장 및 보유

  • 작품 ID, 테스트 인원 수와 임시 세션 정보: 테스트 화면을 열기 위해 Chrome 확장 로컬 저장소에 보관됩니다. 새 테스트 화면을 여는 임시 세션은 생성 후 최대 2시간 동안 유효하며, 저장 기록은 새로운 설정으로 덮어쓰거나 사용자가 삭제할 때까지 남을 수 있습니다.
  • 변수·리스트와 방 상태: 테스트 중 브라우저 메모리에서만 처리되며 관련 탭을 닫거나 페이지를 새로 고치면 종료됩니다.
  • 삭제 방법: 사용자는 Chrome의 확장 프로그램 관리 화면에서 본 확장 프로그램을 삭제하거나 사이트·확장 데이터를 삭제하여 로컬 저장 정보를 제거할 수 있습니다.

5. Chrome 권한 사용 목적

  • Storage: 선택한 작품 ID, 테스트 인원 수와 임시 세션 정보를 로컬에 저장하고 테스트 탭에 전달하기 위해 사용합니다.
  • ActiveTab: 사용자가 확장 아이콘을 누른 현재 탭이 지원되는 엔트리 작품인지 확인하고 작품 ID를 읽기 위해 사용합니다.
  • playentry.org 페이지 접근: https://playentry.org/online* 테스트 부모 페이지와 https://playentry.org/iframe/* 작품 화면에서 여러 화면을 구성하고, 작품의 $ 변수·리스트 상태를 읽고 적용하기 위해 사용합니다.

권한으로 접근한 정보는 위에 설명한 단일 목적의 로컬 멀티플레이 테스트 기능에만 사용합니다.

6. 보안 및 원격 코드

확장 프로그램의 실행 코드는 설치 패키지에 포함되어 있으며 외부 서버에서 실행 코드를 내려받지 않습니다. 일반적인 엔트리 페이지에서는 작품 후킹을 활성화하지 않습니다. 팝업에서 생성한 임시 세션 토큰, 엔트리 사이트의 출처, 부모 테스트 페이지, 작품 ID와 해당 세션에 포함된 작품 화면이 모두 일치할 때만 페이지와 iframe 사이의 메시지를 처리하도록 구성되어 있습니다.

7. Chrome Web Store 사용자 데이터 정책

Chrome API에서 받은 정보는 Chrome Web Store 사용자 데이터 정책과 Limited Use 요구사항을 준수하여 사용합니다.

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

8. 아동의 개인정보 보호

본 확장 프로그램은 별도의 회원가입이나 연령 확인 기능을 제공하지 않으며 개인정보를 의도적으로 수집하지 않습니다. 보호자는 아동이 개인정보나 민감한 정보를 동기화 대상 변수·리스트에 입력하지 않도록 지도해야 합니다.

9. 방침 변경

확장 프로그램의 기능, 권한 또는 데이터 처리 방식이 변경되는 경우 본 방침을 수정하고 변경된 시행일자를 이 페이지에 표시합니다.
