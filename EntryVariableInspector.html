개인정보 처리방침 (Privacy Policy)

시행일자: 2026년 4월 12일

Entry Variable Inspector (엔트리 변수/리스트 실시간 인스펙터) (이하 "본 확장 프로그램")는 사용자의 개인정보 보호를 최우선으로 생각하며, 구글 크롬 웹 스토어의 개발자 프로그램 정책 및 관련 개인정보 보호 법령을 철저히 준수합니다. 본 개인정보 처리방침은 본 확장 프로그램이 사용자의 데이터를 어떻게 취급하는지 안내하기 위해 작성되었습니다.

1. 개인정보의 수집 및 이용

본 확장 프로그램은 어떠한 형태의 개인정보(이름, 이메일, IP 주소, 브라우징 기록 등)도 수집, 저장, 또는 외부 서버로 전송하지 않습니다. 본 확장 프로그램은 오직 사용자의 브라우저 내부(로컬 환경)에서만 동작하며, 서버나 데이터베이스를 별도로 운영하지 않는 순수 클라이언트 사이드(Client-side) 도구입니다.

2. 사용자 데이터 접근 권한 및 목적

본 확장 프로그램은 엔트리(PlayEntry) 작품의 변수, 리스트, 신호, 장면 데이터를 실시간으로 확인하고 수정하기 위해 아래와 같은 최소한의 권한만을 요청합니다.

  • 호스트 권한 (*://playentry.org/*) 및 Scripting 권한: 확장 프로그램이 엔트리 웹페이지 내의 변수/리스트/신호/장면 데이터를 읽고 수정하는 목적으로만 사용됩니다. 해당 데이터는 사용자의 브라우저 내부에서만 처리되며 외부로 전송되지 않습니다.
  • ActiveTab 권한: 사용자가 팝업 또는 사이드바 인터페이스를 통해 현재 작품의 데이터를 확인하고 수정할 수 있도록, 활성 탭에 한정된 기능을 제공할 목적으로만 요청됩니다.
  • 위 과정을 통해 접근되거나 가공된 데이터는 외부로 전송되거나 서버에 저장되지 않으며, 전적으로 사용자의 브라우저 내부에서만 처리됩니다.

3. 개인정보의 제3자 제공 및 공유

본 확장 프로그램은 수집하는 개인정보가 없으므로, 제3자에게 데이터를 제공하거나 공유하는 일 또한 절대 발생하지 않습니다. 사용자의 작품 데이터는 전적으로 브라우저 메모리 내부에서만 처리됩니다.

4. 개인정보의 파기

본 확장 프로그램은 사용자의 개인정보를 수집하거나 영구 저장하지 않으므로 파기할 데이터가 존재하지 않습니다. 확장 프로그램은 실행 중인 작품의 데이터를 실시간으로 읽고 수정할 뿐이며, 브라우저를 닫거나 확장 프로그램을 삭제하면 모든 동작이 즉시 중단됩니다.

5. 아동의 개인정보 보호

본 확장 프로그램은 모든 연령대의 사용자가 안전하게 사용할 수 있습니다. 우리는 만 13세 미만 아동의 개인정보를 포함하여 그 누구의 데이터도 고의로 수집하지 않습니다.
