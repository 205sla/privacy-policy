개인정보 처리방침 (Privacy Policy)

시행일자: 2026년 6월 12일

Entry Online (이하 "본 확장 프로그램")은 엔트리 작품의 $ 접두 변수와 리스트를 같은 온라인 방의 이용자 사이에서 실시간 동기화하는 기능을 제공합니다. 본 개인정보 처리방침은 본 확장 프로그램이 기능 제공 과정에서 사용자 데이터를 어떻게 처리하는지 안내합니다.

비공식 안내: 본 확장 프로그램은 엔트리의 공식 확장 프로그램이 아닙니다.

1. 처리하는 사용자 데이터

본 확장 프로그램은 이용자가 엔트리 작품에서 $입장("Entry Online 아이디") 함수를 호출해 온라인 방에 입장한 경우에만 다음 정보를 처리합니다.

  • 방 식별 정보: 현재 엔트리 작품 ID와 작품 등록에 사용된 Entry Online 아이디
  • 동기화 데이터: 작품 안의 $ 접두 변수·리스트의 이름, 내부 식별자 및 값
  • 연결 정보: 방 ID, 배정 슬롯, 연결 상태 및 일시적인 재접속 토큰
  • 사용량 통계: 작품별 연결 횟수, 수신·송신 메시지 횟수와 바이트 크기
  • 서버 접속 로그: 서비스 보안과 장애 진단을 위해 서버에 기록될 수 있는 IP 주소, User-Agent, 접속 시각 및 요청 정보

변수와 리스트에는 작품 제작자가 입력한 내용이 포함될 수 있습니다. 이용자는 개인정보나 민감한 정보를 동기화 대상 변수·리스트에 저장하지 않아야 합니다.

2. 데이터 처리 목적

  • 같은 작품과 Entry Online 아이디로 선택된 온라인 방의 이용자 매칭
  • 방 참가자 사이의 변수·리스트 실시간 동기화와 재동기화
  • 연결 상태와 사용자 슬롯 번호 표시
  • 서비스 사용량 표시, 용량 관리, 장애 진단 및 비정상 트래픽 방지

수집된 데이터는 위 기능을 제공하고 개선하기 위한 용도로만 사용하며, 광고·신용평가·데이터 판매 또는 이용자 추적 목적으로 사용하지 않습니다.

3. 전송 및 공유

온라인 방에 입장하면 방 식별 정보와 동기화 데이터가 암호화된 WebSocket 연결(wss://online.205.kr/sync)을 통해 Entry Online 서버로 전송됩니다. 동기화 데이터는 같은 방에 참가한 다른 이용자의 브라우저로 전달되므로, 해당 방 참가자는 변수·리스트의 이름과 값을 수신할 수 있습니다.

서버는 Oracle Cloud Infrastructure 환경에서 운영됩니다. 호스팅 제공 목적 외에 사용자 데이터를 광고 사업자, 데이터 중개업자 또는 기타 제3자에게 판매하거나 제공하지 않습니다. 다만 법령에 따른 적법한 요청이 있는 경우 필요한 범위에서 처리할 수 있습니다.

4. 저장 및 보유 기간

  • 변수·리스트 상태: 현재 방의 재동기화를 위해 서버 메모리에만 임시 보관되며, 방의 마지막 연결과 재접속 예약이 모두 사라지면 삭제됩니다. 데이터베이스에는 원본 값을 저장하지 않습니다.
  • 재접속 토큰: 브라우저 메모리와 서버 메모리에만 일시적으로 보관되며, 연결 종료·만료 또는 방 폐기 시 삭제됩니다.
  • 사용량 통계: Entry Online 계정과 작품 ID를 기준으로 일자별 합산하여 저장합니다. 작품 등록을 해제해도 누적 총합을 제공하기 위해 유지되며, 해당 Entry Online 계정을 삭제하면 함께 삭제됩니다.
  • 서버 접속 로그: 서버 또는 리버스 프록시에서 로그가 생성되는 경우 운영 로그 회전 정책에 따라 오래된 파일부터 삭제합니다. 보안 사고 조사나 법령상 보존 의무가 있는 경우를 제외하고 영구 보관하지 않습니다.
  • 확장 로컬 저장소: 최근 연결 상태를 Chrome 로컬 저장소에 저장합니다. 오래된 연결 상태는 자동 정리되며 확장 프로그램을 삭제하면 함께 제거됩니다.

5. 권한 사용 목적

  • 엔트리 사이트 접근: 지원되는 엔트리 작품 실행 페이지에서 변수·리스트와 작품 실행 상태를 읽고 동기화된 값을 적용하기 위해 사용합니다.
  • ActiveTab 권한: 이용자가 확장 아이콘을 눌렀을 때 현재 탭의 엔트리 작품 ID와 연결 상태를 팝업에 표시하기 위해 사용합니다.
  • Storage 권한: 최근 연결 상태를 팝업에 표시하기 위해 확장 프로그램의 로컬 저장소를 사용합니다.
  • online.205.kr 호스트 권한: Entry Online 동기화 서버와 암호화된 WebSocket 연결을 열기 위해 사용합니다.

6. 이용자의 선택과 데이터 삭제

  • $나가기 함수를 호출하거나 작품 실행을 정지하면 현재 온라인 방에서 나가며 실시간 전송이 중단됩니다.
  • Chrome에서 본 확장 프로그램을 삭제하면 확장 로컬 저장소와 권한이 제거됩니다.
  • Entry Online의 작품 등록 해제 기능은 새로운 입장을 중단하지만 과거 사용량 통계는 계정 총합에 유지됩니다.
  • Entry Online 계정을 삭제하면 작품 등록과 계정에 귀속된 사용량 통계가 함께 삭제됩니다.
  • 개인정보 및 접속 로그 관련 요청은 아래 문의처로 접수할 수 있습니다.

본 확장 프로그램은 Chrome Web Store 사용자 데이터 정책과 Limited Use 요구사항을 준수합니다. 사용자 데이터는 본 확장 프로그램의 단일 목적인 엔트리 작품 온라인 변수·리스트 동기화 기능을 제공하거나 개선하는 데 필요한 범위에서만 사용됩니다.

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
